# Lower bound 1.57: the dashboard calls `st.dataframe(width="stretch")` and
# `st.plotly_chart(width="stretch")`. Earlier 1.x releases either don't accept
# the literal "stretch" value or accept it inconsistently across elements;

# Upper bound <2: streamlit and plotly both ship breaking changes across

# so leaving the upper bound open would invite silent runtime breakage on
# the next major release.
